# Paradoxical Sajid – Book Overview

A simple and elegant book introduction webpage for **Paradoxical Sajid**, written by Arif Azad. This project presents an overview of the book, highlighting its themes of faith, doubt, philosophy, science, and logical reasoning.

## 🌐 Project Overview

The webpage provides a clean and readable presentation of the book using a dark-themed design with warm golden accents. It focuses on typography, readability, and a responsive layout to create a comfortable reading experience.

## ✨ Features

- **Elegant Dark Theme:** Dark background with golden highlights.
- **Book Cover Display:** Shows the book cover with a hover animation.
- **Typography:** Uses Georgia and Times New Roman for a classic reading experience.
- **Readable Content:** Well-spaced paragraphs with justified text alignment.
- **Drop Cap Effect:** Highlights the first letter of the description.
- **Hover Animation:** Adds a subtle zoom effect to the book cover.
- **Responsive Design:** Adapts to desktop, tablet, and mobile screens.

## 🛠️ Technologies Used

- CSS3

## 📱 Responsive Design

The webpage is optimized for different screen sizes:

- Desktop: Full-width content with spacious layout.
- Tablet: Adjusted padding, image size, and typography.
- Mobile: Compact layout for a better reading experience.

## 📖 About the Book

**Paradoxical Sajid** by Arif Azad explores thought-provoking questions about faith, atheism, the existence of God, science, religion, and human reasoning.

Through conversations and storytelling, the book encourages readers to explore different perspectives, question assumptions, and reflect on their beliefs.
